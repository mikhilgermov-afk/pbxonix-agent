# Security reports

Send vulnerability reports to info@pbxonix.com. Include the agent version,
affected component, impact and a minimal reproduction with synthetic data.
Do not include credentials, recordings, customer phone numbers or production
logs in public issues.

The agent runs on Linux PBXs. Python 3.6 compatibility supports existing
Issabel installations; it does not extend the security support of Python or
the operating system. Prefer a supported operating system and Python release
where your PBX supports them.

Release downloads include SHA256SUMS. Verify the artifact before installing.
Checksums detect changed downloads; they are not a separate publisher signature.
