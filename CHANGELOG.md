# Changelog

## 0.11.1 - 2026-10-07

First public GitHub release of the agent currently distributed by PBXonix.

- Publish the local agent and installation scripts under Apache License 2.0.
- Include collectors for PBX health, SIP/PJSIP trunks, operators, queues,
  call quality and privacy-filtered reports.
- Include Linux tests, Python 3.6 checks and tag-based releases.
- Add source repository, security contact and release instructions.

The agent runtime is unchanged from the existing PBXonix 0.11.1 package.
